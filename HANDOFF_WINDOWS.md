## 3. Steps on Windows
```bash
git stash            # only if there are uncommitted local edits
git pull
git stash pop        # if stashed; resolve conflicts, preferring the newer Linux files
```
Then recreate the environment (do NOT copy the Linux venv):
```bash
python -m venv medical-stt-env
medical-stt-env\Scripts\activate
pip install -r "Source Code/requirements.txt"
```
Notes: GPU scripts need a CUDA build of torch; Linux paths/shell commands in docs need Windows adaptation; use `Path`/forward slashes.

## 4. ⚠️ Files NOT in Git – user must copy by hand
These are git-ignored, so `git pull` will NOT bring them. Transfer via USB / cloud drive / secure transfer.

| What | Where (repo-relative) | Why ignored |
|---|---|---|
| **`.env`** (API keys: `GEMINI_API_KEY`, `OPENAI_API_KEY`, `JWT_SECRET_KEY`, `ENABLE_LOGIN`, optional `HF_TOKEN`) | repo root `.env` | secrets – never commit or paste into chat |
| **All CSV files** (`*.csv` is ignored in `Source Code/.gitignore`) | `Source Code/analysis_CAR_cases_only.csv`, `Source Code/medical_report*.csv`, `Source Code/*_stt.csv`, **`Source Code/all_audio_soap/ground_truth/*.csv`**, **`Source Code/all_audio_soap/predicted/*.csv`** | pattern `*.csv` |
| **`Source Code/users.json`** | `Source Code/users.json` | credential store |
| **Audio files** (`.wav .mp3 .m4a .flac .ogg .aac`, ~1 GB) | `audio_sample/audio_recordings/Audio_Recordings/` | large |
| Whisper model cache / weights (`*.pt`, `*.bin`) | usually `~/.cache/whisper` or HF cache | large – re-download automatically on Windows if missing |
| Cached `*_segments.json` | wherever generated | optional; regenerated by re-running Whisper |
| Logs (`*.log`) | – | optional |

Easiest approach: zip only the ignored items (ground_truth + predicted CSVs, `analysis_CAR_cases_only.csv`, `users.json`, `.env`, audio folder) and extract them into the same relative locations on Windows.
Optionally only copy audio for the cases you still need, to save space.

Do not copy: `medical-stt-env/`, `__pycache__/`, `Lib/site-packages`.
